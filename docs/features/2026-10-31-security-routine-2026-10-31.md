# Security sweep 2026-10-31: tornado

**Branch:** security/routine-2026-10-31
**Date:** 2026-10-31

## Summary
Moves `tornado` from 6.5.9 to 6.6 in `uv.lock`.

## Motivation
Three advisories published 2026-10-28, all fixed in 6.6. Tornado runs the local
JupyterLab server (via jupyter-server and ipykernel).
- GHSA-pcg2-g6cj-q92c: quadratic CPU when parsing folded HTTP headers.
- GHSA-r4j5-9xpp-3985: event loop blocking from chunked bodies with many small chunks.
- GHSA-pw9p-v7r6-gx4p: open redirect in `RedirectHandler` via protocol-relative URLs.

## What changed
- `uv.lock`: the `tornado` entry only. `pyproject.toml` is unchanged.

## Notes
- 6.6 was published 2026-10-21, outside the 7-day cooldown. It is the lowest fixed version.
